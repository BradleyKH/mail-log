8.1.2 INPUT TO CATEGORY LOOKUP TAELE

Option 2 allows the user to input records into the Category Lookup
Table. A current list of the records in the table is displayed within the
routine. The user will then enter the Category and Description for each new
record. To end the input and exit the routine, the user must enter a_ return
at the prompt for 'CATEGORY >'. A new listing of the records in the table
will be displayed, and the user will then be returned to the Input menu.
