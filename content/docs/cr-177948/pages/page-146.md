11.3.2 DELETE FROM CATEGORY AND LOCATION LOOKUP TABLES

Options 2 and 3 allow the user to delete a record from the Category
and Location lcokup tables within the data base. A listing of the current
lookup table Is displayed at the terminal screen within each delete routine.
When the deletion has been completed, the user will be returned to the pro-

gram main menu. The following examples Illustrate these options.
