7.5.3 W.A. REPORT

The Work Authorization (W.A.) hourly report displays hourly sum
maries by fiscal year for each W.A. and program assignment, such as 400
(NASA) and 493 (DOD). The following Is an example of the W.A. hourly report.
See Appendix H-3 for an example of the Work Authorization hourly report

output format.
