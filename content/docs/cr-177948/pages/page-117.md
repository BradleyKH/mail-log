There is a specialized 'ALL' search which outputs all documents In
the Change Request file data base. No terminal display of the records is
performed. However, the number of CR's found wil! be displayed. The output
Is automatically spooled to the system printer located in the SPO computer
room at NASA/LaRC in Hampton, Virginia. Refer to Appendix D-3 for an example
of the Change Request ALL Search report output format.

The Vehicle search also has a special quality. A group of vehicles
may be found by using the first and last valid vehicle option. For example,
If a user sets the first valid vehicle as 197 and is searching for vehicle
number 200, not only would al! documents containing vehicle 200 be found, but
also those with numbers 1978, 199S, and 200S, where S represents all subsequent
vehicles. Default for the first and last valid vehicle numbers are
the user desired vehicle number. This will therefore search for only one
vehicle value.

The SOP Engineer search option provides a report of the responsibie
engineer(s) for each Standard Operating Procedure. Refer to Appendix 1-3 for
an example of the Responsible Engineer SOP Report output format.
