Option 79 allows the user to receive a multiple |ine message from
another user currently logged into the system. This option is also _ invoked
by option 12 on the OAS main menu (see section 4.0 of this document).
When a user receives the following message:

1HX* XXX (user #) AT HH:MM
INCOMING CALL ... TYPE PHONE !'

where XXX is a user ID and HH:MM 1s the time in hours and minutes, this
indicates that the user, after exiting his current program, should type '79!
at the Exit menu. A list of the currently available users will be displayed
on the terminal screen, along with a list of available commands. Next,
"PLEASE HOLD ... INCOMING CALL! will be displayed. A longer message may
take several minutes to be typed in by the sender. After the message has
been sent, the prompt 'SEND>' will appear, at which a reply may be sent.
This operation is described under option 69 In the previous paragraph. See
