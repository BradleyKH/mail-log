7.3.5 DELETE A CATEGORY FROM THE LOOKUP TABLE

Option 5 allows the user to delete a record from the category
lookup table. A listing of the records currently contained In the lookup
table is displayed within the delete routine. When deleting has been completed,
the user will be returned to the Delete menu. See the fol towing

example.

SELECT OPTION BY ENTERING NUMBER (RETURN TO QUIT) > 5

THIS PROGRAM DELETES A RECORD IN THE CATEGORY LOOKUP TABLE
