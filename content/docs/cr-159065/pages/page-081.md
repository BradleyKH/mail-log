Step #12

```text
WHICH PRINT ALL OPTION DO YOU WISH:
DRAWING AND E.O.s (DE)
E.O.'s ONLY (EO)
```

If DE, go to #13
If EO, go to #16

Step #13

```text
THIS IS THE PRINT ALL ROUTINE
ALL DRAWINGS STORED IN THE DRAW FILE WILL BE SPOOLED AND A TOTAL
COUNT OF THE DRAWINGS WILL BE GIVEN
```

Step #14 Drawing data is displayed on the terminal for each drawing found along with referenced E.O.'s. See Figure 41.

Step #15

```text
THERE ARE XXX DRAWINGS IN THE DRAW FILE
```

Where XXX represents the number of drawings found. Go to #19.

Step #16

```text
THIS IS THE PRINT ALL ROUTINE
ALL ENGINEERING ORDERS STORED IN THE EO FILE WILL BE SPOOLED AND
A TOTAL COUNT OF THE DRAWINGS WILL BE GIVEN
```

Step #17 Engineering order data is displayed on the terminal for each EO found. See Figure 42.

Step #18

```text
THERE ARE XXX E.O.'s IN THE EO SUBFILE
```

Where XXX represents the number of engineering orders found.
Go to #18.

Step #19 Output file is automatically spooled to the high speed printer; exit the SEARCH mode.

Step #20

```text
THIS IS THE REVISION ACTION DUE SEARCH ROUTINE
ALL DRAWINGS WITH FIVE (5) OR MORE E.O.'s ARE FOUND AND SPOOLED
```

Step #21 Drawing data is displayed on the terminal for each drawing sheet found See Figure 41.
