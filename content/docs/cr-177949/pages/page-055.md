The Contract Analysis report generator has multi-user capability. Any
of the available reports may be run by more than one user’ simultaneously.
Note that any listings, however, represent the data base as seen by the user
running the report, and that the data may have been updated by another user.

The following sections contain illustrations and instructions for
running each of the reports. It should be noted that entering a carriage
return at the report generator menu will return the user to the Contract

Selection menu shown in section 1.1 of this document.
