11.2 UPDATE OPTION

When the update option Is selected from the main menu and the proper
security clearance has been passed, the Government Furnished Property file

update menu will appear as follows:

GOVERNMENT FURNISHED PROPERTY UPDATE MENU FOR THE SCOUT PROJECT OFFICE

AVAILABLE OPTIONS ARE AS FOLLOWS

\1. Update GSE Record

\2. Update Category Lookup Table
\3. Update Location Lookup Table
\4. Sort and Housekeeping Routine
