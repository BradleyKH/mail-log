The Change Request file main menu has’ six (6) options: options 1,
2, and 4, INPUT, UPDATE, and ARCHIVE, which are privileged options and require
a security clearance, and options 3, 5, and 6, SEARCH, QUICKIE, and
REBUILD, which have open access. AI! options are discussed in the following

sections.

security clearance has been passed, the Change Request file Input routine
