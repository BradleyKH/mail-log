7.2.4 TRANSFER OF COMPONENTS

Option 8 generates the Motor Transfer menu for the Motor Information

file, which appears as follows:

MOTOR TRANSFER MENU FOR THE SCOUT PROJECT OFFICE

AVAILABLE OPTIONS ARE AS FOLLOWS

\1. Move Vehicle to Vehicle

Z. Move Vehicle to Spare

\3. Move Spare to Vehicle

\4. Move Spare’ to Spare

\5. Move Spare to Test Expended

SELECT OPTION BY ENTERING NUMBER (RETURN TO QUIT) >

to another data file or to another location in the same data file. The user
