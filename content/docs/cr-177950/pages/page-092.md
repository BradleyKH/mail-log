All search examples illustrated in this section use report formats
that have been modified for use in this document. When run from the program,
these reports appear much wider or the terminal screen and in printer output
format.

Options 1, 2, 3, and 4 are all partial searches and operate very
similarly. The user may first choose to search froma single or category
or from all categories. Options 1, 2, and 3 require the entry of a search
value, such as 'TEST' for the Description search. Since this is a partial
search, searching on 'TEST' would retrieve those records containing both
"TESTING PHASE' and 'ORDERS CONTESTED! in the description field. Option 4
requires no further entries since it allows the user to search on an entire
