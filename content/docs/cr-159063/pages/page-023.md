3.1.2.1 OPENING HEADER

This attaches to the F_MAIL UFD and resumes the running of the main
MAIL LOG enter program, BFILE.

WELCOME TO SPADS
MAIL LOG FILE
DO YOU WISH TO WORK WITH THE DIR/REPORT DATA --- ENTER DIR

OR DRAWING DATA --- ENTER DRAW
OR DAILY CORRESPONDENCE --- COR
OR QUIT --- QU

In order for the user to select one of the four modes of operation,
one of three main data base subfiles must first be designated as follows:

[DRAW

This attaches the user to the F_DRAW UFD and resumes operation of
the *DRAW program. Likewise, if DIR was selected, *DIR program would be
resumed on the F_DIR UFD. If COR was selected, the user remains on the F_MAIL
UFD and continues as normal.
