2.3 PROGRAM EXIT

To leave a program, the user must enter a zero as shown on the menu.
Note that in most cases a carriage return is interpreted as a zero entry.
Exit from a menu returns the user to the previous menu until the exit menu
Is reached. The user may then display the spool queue, display ail users
currently on the system, send or receive a message, return to the
main selection menu, or logout. These options are covered in further detail

In section 2.8 of this document.
