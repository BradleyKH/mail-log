7.4.2 SUB-JOB ORDER REPORT

The Sub-job order cost report displays dollar summaries by fiscal
year for each sub-job order, and program assignments, such as 400 (NASA) and
493 (DOD). See section 7.4.1 of this document, Program report, for an
example of the user options required for executing this report. See Append!x

G-2 for an example of the Sub-job order cost report output format.
