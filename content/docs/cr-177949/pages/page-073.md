7.6.1 HOURLY REPORT

The proration hourly report displays hourly data by vehicle, phase,
and program. There are three (3) main options for report formats:
(1) Regular - showing tasks by mod
(2) Special R= - showing task R only by subtask number
(3) Subjoborder - showing each task by joborder alpha-subtask.
The following Is an example of the proration hourly report.

See Appendix | for an example of each proration hourly report output format

(I-1 for Regular, !-2 for Special R Subtask, and I-3 for Sub-job Order).
