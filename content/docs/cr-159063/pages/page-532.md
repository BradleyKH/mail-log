6.3 MISCELLANEOUS VARIABLES AND ARRAYS

This Section provides a description of all Miscellaneous Variables
and Arrays used by each MAIL LOG subfile program. The following items are

given for each:

(A) Variable or Array name
(B) Description of Variable or Array name

(C) Size of Variable or Array in characters
(D) Type of characters
