3.2 EMERGENCY / RECOVERY

The following procedures have been designed to aliow the user to

recover and continue SPADS operations should an error occur.
3.2.1 SOFTWARE / OPERATOR ERRORS FOR SPADS

If an error occurs and sends the user out of a SPADS program Into
the PRIME 750 operating system, the following message will be displayed:
‘ERROR: C ALL / SPADS'. The user should then type 'C ALL' and return.
This step Is very Important to the recovery procedure since [t closes all
open files that the user was using. The user should then type 'SPADS' and

enter a return to restart the SPADS main menu.
