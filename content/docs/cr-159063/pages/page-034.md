4.1.28 HARDPT

This subroutine is used by the SEARCH MODE to format for the output -

4.1.29 UPDATE

This subroutine is used by the INPUT MODE to delete or change
document records in the ACTION DUE DATE subfile. The updating of this file
is determined by checks on specified words in the subject of the referencing
document. Flowchart Figure 5.4.1-29 depicts the flow diagram for this
subroutine.
