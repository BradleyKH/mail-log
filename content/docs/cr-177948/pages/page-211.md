16.0 SCHEDULER FILE

This file fs a personne! activity tracking data base designed for
the Scout Project Office, NASA / LaRC. The data base consists of two ( 2 )
files: the Personnel Information file and the Activity Schedule file.

Information for each record In the Activity Schedule file Is

stored in the following fields:

```text
USER ID CODE            ACTIVITY CATEGORY       DESCRIPTION
START DATE              START TIME              CONF I RMAT ION
END DATE                END TIME                SEQUENCE NUMBER
```

Information for each record In the Personne! Information file ts

stored in the following fields:

```text
USER ID CODE            NAME                     ADDRESS

ADDITIONAL ADDRESS      CITY                     STATE

ZIP CODE                EXTRA ZIP CODE           AREA CODE

PHONE NUMBER            SECONDARY PHONE NUMBER EXTENSION
```
