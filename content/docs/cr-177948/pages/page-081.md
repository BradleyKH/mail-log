7.2.4.1 TRANSFER VEHICLE TO VEHICLE

Option 1 allows the user to move a component from one vehicle in the
vehicle file to another vehicle In the vehicle file. The following example

Illustrates option 1.

SELECT OPTION BY ENTERING NUMBER (RETURN TO QUIT) > 1

THIS PROGRAM WILL TRANSFER A COMPONENT FROM THE VEHICLE FILE
TO ANOTHER VEHICLE IN THE VEHICLE FILE.

PLEASE ENTER INFORMATION FOR THE COMPONENT THAT IS TO BE MOVED:
VEHICLE NUMBER (TYPE QUIT TO EXIT) > S-198

ALGOL 11
ALGOL IIIA
CASTOR ||
CASTOR IIA
ANTARES 11
ANTARES JIA
ANTARES | 1B
ANTARES {11
ALTAIR IIIA

OOnAAMNHPWH —

ENTER STAGE NUMBER > 9

1 MOTOR
2 CASE

3 NOZZLE
4 IGNITER

5 MISCELLANEOUS
6 CONTAIN/DOLLY

ENTER CATEGORY NUMBER > 1

ENTER THE COMPONENT SERIAL NUMBER > E29

PLEASE STAND BY .... COMPONENT SELECTION NOW BEING MADE.
COMPONENT HAS BEEN FOUND,

PLEASE ENTER VEHICLE TO WHICH THE COMPONENT |S TO BE REASSIGNED:

VEHICLE NUMBER (TYPE QUIT TO EXIT) > S666

VEHICLE NUMBER (TYPE QUIT TO EXIT) > QUIT
