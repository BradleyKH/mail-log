4.2.16 CMAIN

This subroutine is used by the SEARCH MODE to format and display on
the terminal the entire data record found during a CONTRACT NUMBER search,
4.2.13. This procedure also formats the data record for the output file to
be spooled on the high speed printer.

If many document records are found during a search and it is observed
that needed information will soon disappear from the screen, the user may
temporarily stop terminal display by depressing the space bar. Terminal
display may be restarted by depressing the 'Q' key. Flowchart Figure 5.4.2-16
depicts the flow diagram for this subroutine.
