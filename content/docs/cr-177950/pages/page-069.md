6.5.3.2 APPROVED OR DISAPPROVED RECORDS

Option 2 generates a report of all records containing APPROVED or
DISAPPROVED In the Current Status data field. If no such records exist in
the data base, a message stating so will be displayed, and the user will be
returned to the Report menu. If records are found, the report will be displayed
at the terminal screen and the user must indicate whether printer
output is desired. The user will then be returned to the Report menu. See

the following example.

ENTER OPTION > 2

1 LDEF
2 OOP
3 ACEE
4 TRW
5 ERBE
