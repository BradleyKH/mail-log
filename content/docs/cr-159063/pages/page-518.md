6.1.3 TEMPORARY WORKING STORES

6.1.3.1 MAIL CORRESPONDENCE

The CORRESPONDENCE program uses several temporary working storage

files for outputting, rebuilding, restructuring, or sorting various subfile

‘data records.

```text
NAME             DESCRIPTION

OUT          :   OUTPUT FILE

REVS             REVISION DATA FILE

DATE             CURRENT DATE & DAILY
```

DOCUMENT COUNTER

```text
IM               DAILY INCOMING MAIL

OM               DAILY OUTGOING MAIL

VC               DAILY VOUGHT CORRESPONDENCE

T1               SUBJECT SEARCH FOUND FILE

T2           SUBJECT SEARCH FOUND FILE
```
