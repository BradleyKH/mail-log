6.5.3.3 CANCELLED OR WITHDRAWN RECORDS

Option 3 provides areport of those records having a status of
CANCELLED or WITHDRAWN. If no such records are found in the data base, a
message stating so will be displayed, and the user will be returned to the
Report menu. If records are found, the report will be displayed at the
terminal screen. After indicating whether printer output is desired, the

user will be returned to ihe Report menu. See the following example.

ENTER OPTION > 3

1 LDEF
2 ODP
3 ACEE
4 TRW
