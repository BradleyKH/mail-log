security clearance has been passed, the Mark Up file delete routine operates

as follows:

Enter Option > 2
WELCOME TO THE MARK UP FILE REVISE ROUTINE
PLEASE INPUT INFORMATION BETWEEN THE EXCLAMATION MARKS
Enter MARKUP # to be REVISED or DELETED > 1327

STAND BY. SEARCH NOW IN PROGRESS.
