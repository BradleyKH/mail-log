4.3.4.2 ACTION/RESPONSE DURING ARCHIVE MODE

Step #1

```text
DO YOU WISH TO ARCHIVE DRAWINGS OR E.O.'s (DR OR EO)
```

If DR, go to #2
If EO, go to #5

Step #2

```text
WELCOME TO THE DRAWING FILE ARCHIVE ROUTINE.
HOW MANY DRAWINGS DO YOU WISH TO ARCHIVE
XX
```

Enter number XX

Step #3

```text
WHAT IS THE DRAWING NUMBER OF THE DRAWING YOU WISH TO ARCHIVE
```

Enter number; 14 characters.

Step #4 Pause for system housekeeping to be completed. Repeat Step #3 XX number of times. Go to #7.

Step #5

```text
PLEASE STAND BY.  SYSTEM IS NOW ARCHIVING UNREFERENCED E.O.'S
```

No user response required.

Step #6 As each E.O.'s is archived the following message is displayed on the terminal:

```text
E.O. NNNNNN HAS BEEN ARCHIVED.
```

Where NNNNNN represents the engineering order number.

Step #7 Exit ARCHIVE mode when done.
