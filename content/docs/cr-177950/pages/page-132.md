Option 3 generates a Special Parts Inventory report for the Parts
File. This report may be formatted using the entire Parts File, the Spare
Parts only, or the Drawing Parts only. All of these reports may be’ sorted
either by part number or by generic number. The report is sent directly
to the printer for spooled output and is not visible on the terminal screen.
After responding to the spool! menus options, the user will be returned to the

Report menu. See the following example.
