8.5.6 SECURITY TABLE UPDATE

The security table update option allows the Financial Security Monitor
to change the user security table. Only the Security Monitor has the clearance
to access and modify the security table!! Each record may be deleted or
modified by ID code. If an ID code is not found in the table, the Security
Monitor may choose to make that ID code a new entry into the security table.
For security reasons, the access control codes for each user are not defined
within this document. The following example illustrates this update option.
