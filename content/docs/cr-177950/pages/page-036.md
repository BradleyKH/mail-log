Exit Telemail as described in section 5.2 of this document. At the PRIMOS
level prompt ‘OPTION: OAS/SPADS/LO' type 'OAS'. Enter OAS and select the
OAS Word Processing menu import option. Import the previously recorded COMO
file which contains the incoming Telemail document. In the example, the
PRIMOS filename was COM0840521.130356. Enter the OAS Word Processing menu

edit option to delete the extraneous material and edit as desired.
