6.5.3.4 SEARCH AND PRINT ALL

Option 4 provides a listing of all of the records In the CCR File
data base. The report Is displayed at the terminal screen along with a
prompt for the user to indicate whether printer output is desired. After
entering a 'Y' or an 'N' for printer output, the user will be returned to

the Report menu. See the following example.
