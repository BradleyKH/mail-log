8.5.2 RATE TABLE UPDATE

The rate table update option allows the user to change the rate
table values for a particular task and fiscal year. Both the hour and dollar
rates may be changed, but never deleted. Blank or zero entries Indicate
that the field Is to remain unchanged. The following example illustrates
this option.
