7.2.5 UPDATE STAGE, CATEGORY, AND LOCATION LOOKUP TABLES

Options 5, 6, and 7 allow the user to update records In one of the
lookup tables used in the Motor Information file. A listing of the current
lookup table is displayed at the terminal screen within each update routine.

The following examples [llustrate these last three options.
