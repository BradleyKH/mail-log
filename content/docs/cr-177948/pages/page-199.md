15.0 DAILY WORK ITEMS FILE

This file fs an accumulation of the Daily Work Items (DWI 's)
received from launch sites. The primary purpose of this file Is to malintain
a log of DWI's and to provide a method of rapid retrieval using vartous

search criteria.
Information for each record Is stored in the following fields:

```text
DWI NUMBER            LOCATION           ENGINEER
ORIGIN DATE           t}NPUT DATE         TITLE
REFERENCE DRAWING     REFERENCE E.0.     REFERENCE C.C.R.

OTHER REFERENCES                        EFFECTED SYSTEMS
```

lows:

The Daily Work Items File main menu has five (5) options: options
1, 2, and 3, INPUT, UPDATE, and DELETE, which are privileged options and
require a security clearance, and options 4 and 5, SEARCH and SORT &
HOUSEKEEPING ROUTINE, which have open access. All of these options are

discussed in the following sections.
