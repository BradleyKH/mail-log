8.2.3 UPDATE THE CATEGORY LOOKUP TABLE

Option 3 allows the user to update a record in the category lockup
table. A listing of the records in the lookup table is displayed within
the update routine. The user enters the record number of the record to be
changed at the prompt 'RECNO?>'. The user will then be prompted for the

Category and Description of the updated record. Entering a carriage return

at a prompt for a new field value will leave that particutar field unchanged.
To exit the routine, the user will enter a carriage return at 'tRECNO?>'. The
user will then be returned to the Update menu. See the following example.

SELECT OPTION BY ENTERING NUMBER (RETURN TO QUIT) > 3
