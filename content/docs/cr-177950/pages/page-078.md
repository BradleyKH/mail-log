7.1.3 INPUT TO SCC FILE

Option 3 allows the user to input records into the SCC file. Due to
existing hardware limitations, no special input screen has been developed for
the SCC file. Input for this fille operates similarly to the input routine

for the category lookup table. See the following example.

SELECT OPTION BY ENTERING NUMBER (RETURN TO QUIT) > 3
THIS PROGRAM INPUTS TO THE SCC FILE
