REMARKS : IMPLEMENTED BY REVISION |

Option 2 performs the Date Issued search. This routine searches
on one date only rather than a range of dates. The user must enter the

desired date In the format MM/DD/YY. See the following example.

SELECT OPTION BY ENTERING NUMBER (RETURN TO QUIT) > 2
THIS SEARCH ROUTINE PERFORMS THE DATE ISSUED QUERY / RETRIEVAL

THE CURRENT PROJECTS AVAILABLE FOR SEARCHING ARE:

(1) LDEF
(2) OOP

(3) ACEE
(4) TRW

(5) ERBE
(6) ALSO
( 7) ~~ UARS
(8) STFE

ENTER PROJECT # TO BE SELECTED (ZERO - 0 - FOR ALL) > ** return **
YOU HAVE SELECTED 411 RECORDS FROM THE CCR FILE FOR QUERY

ENTER DATE ISSUED TO BE SEARCHED ON > 5/3/83
