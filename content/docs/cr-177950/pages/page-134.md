9.0 FIPPS PROCESSING FILE

The FIPPS Processing file main menu appears as follows:

PROCESSING DOCUMENTS DATA FILE (FIPPS)

Avallable Options are as follows:

```text
(0) Exit     - quit program (Return)
(1) Input    - add new record to file
```

(2) Update - revise or delete record
(3) Search - query & retrieve records
(4) Archive - purge & save old records

Enter Option >

In order to access the Input, Update, and Archive routines, the
user must have the proper security clearance (placed Internally on the user

ID). The Search routine has cpen access to all users.
