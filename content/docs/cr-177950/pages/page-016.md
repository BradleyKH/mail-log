2.6.2 FORTRAN UPDATE FORMS

FORTRAN update forms are generated similarly to the FORTRN input
forms. Data is entered between exclamation points one line (or one field)

at a time. For further details refer to section 2.5.2 of this document.

2.7 ERROR MESSAGES

Some data field values are checked internally for accuracy. If an
incorrect value is entered, an error message iis displayed at the terminal

screen, and the user is required to reenter the value.
