2.3 PROGRAM EXIT

To leave the Analysis program the user must enter a zero as shown
on the menu. Note that in most cases a carriage return is interpreted as a
zero entry. Exit from a menu wil! return the user to the previous menu until
the Analysis Contract selection menu is reached. The user can then display
the spool queue, display all users currently logged into the system, return
to the SPADS master menu, or logout. These options are discussed In further

detall in section 2.4 of this document.
