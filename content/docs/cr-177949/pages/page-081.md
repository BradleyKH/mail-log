7.7 DISCREPANCY REPORT

The Discrepancy report searches the financial data base for a wide
range of errors and Irregularities, including records which are in overrun
condition. Records found are formatted for output to the printer in the
same fashion as In an Entire Record (see Appendix C-1 for an example of an
Entire Record Format).

running a Discrepancy report.
