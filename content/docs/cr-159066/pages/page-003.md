MAIL LOG
PROGRAM SUMMARY AND SPECIFICATIONS
NASA CONTRACTOR REPORT

DANNY K. HARRIS

May 1979

A summary of software specifications, generalized flowcharts, sample
outputs, functional mode descriptions, and data base definition for computerization
of an existing documentation control and filing system called
Mail Log. Minimum requirements for this program consist of a 16 bit computer
with a 64K dedicated memory, and accompanying peripherals for input, output,
and storage.
