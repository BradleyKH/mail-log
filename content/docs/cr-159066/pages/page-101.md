7.3 DRAWING/ENGINEERING ORDER - OUTPUT FURMATS

Outputs produced while operating within the drawing or engineering
order subfile may result during two modes: INPUT and SEARCH.

7.3.1 INPUT MUDE FOR DRAWING/E.O.

Uutput resulting from the INPUT MODE is a special message displayed
on the user terminal regarding the status of a particular drawing sheet.
This occurs while inputting a new engineering order on a drawing sheet. If
the sheet has three or more E.0.'s already assiaqned, one of three possible
messages will be displayed to the user. See Figure 7.3.1.1.
