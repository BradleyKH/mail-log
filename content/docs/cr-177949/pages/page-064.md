7.4 PROGRAM COST

The Contract Analysis cost report menu appears as_ follows:

ENTER OPTION: 4
FINANCIAL ANALYSIS COST REPORT GENERATOR

(1) PROGRAM REPORT ( EACH TASK FOR CONTRACT 16200 )
(2) SUB-JOBORDER REPORT ( EACH TASK FOR CONTRACT 16200 )
(3) W. A. REPORT ( EACH W.A. FOR CONTRACT 16200 )

ENTER NUMBER ONLY :: (RETURN TO EXIT)
ENTER OPTION:

It should be noted that typing 'QUIT' at any point within the cost

report routines will return the user to the previous menu.
