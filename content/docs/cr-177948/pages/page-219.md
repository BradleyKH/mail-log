16.2.3 UPDATE CATEGORY LOOKUP FILE

Option 3 allows the user to update records in the Category Lookup
file. A listing of the current categories available Is displayed within
the update routine. A carriage return entered at the prompt 'CAT>*! will
complete the update. After the new list of categories Is displayed at the
terminal screen, the user is returned to the program main menu. Refer to

the example below.

SELECT OPTION BY ENTERING NUMBER (RETURN TO QUIT) > 3
THIS PROGRAM UPDATES RECORDS IN THE CATEGORY LOOKUP TABLE
