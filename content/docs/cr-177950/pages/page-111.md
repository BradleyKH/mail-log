8.2.2 UPDATE A DRAWING PART

Option 2 allows the user to update arecord within the Parts File
data base. The user must first enter the appropriate drawing number. if
no records are found having the desired drawing number, a message stating so
will be displayed and the user may enter another drawing number or a_ enter
a carriage return to exit. After entering a valid drawing number, the user
must enter the item number of the record to be updated. If the desired
record jis found, it will be displayed In an update screen Identical to the

found will be displayed on the input / update screen. To retrieve the subsequent
