8.7 BOOK ALL OUTPUTS

The book all output routine develops two (2) reports for output of the
entire data base for the selected contract. The first output is in a listing
format displaying the task, subtask, work authorization, system number,
title, and RBK data fields of each record. A sample of this type of listing
is contained in Appendix B-1 of this document. The second output prints all
the data fields of each record, an example of which Is contained In Appendix
C-1 of this document. Each output is spooled Individually. Due to their

stze both should be spooled to a line printer. See the following example:
