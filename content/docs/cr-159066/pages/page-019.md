The DRAWING subfile contains all sheet one (1) information pertaining
to a specific drawing. If the drawing has more than one sheet, additional
information pertaining to each following sheet is contained in the SHEET subfile.
Therefore, the DRAWING and SHEET subfiles together form all drawing data
contained within the data base. The E.0. subfile contains pertinent information
related to all Engineering Orders.
