16.1.2 {NPUT ACTIVITY FOR INDIVIDUAL WITH VERIFICATION

Option 2 allows the user to input records Into the Activity Schedule
file with verification of conflict of activity dates. If a conflict is found
(an activity previously scheduled for the desired date) it will be displayed
in report format at the terminal screen, with the option to add a record for
that date. If the user responds with 'Y', the input screen will be displayed
and closing messages identical to those illustrated for option 1 will be
displayed. If the user responds with 'N' the user must again enter the correct
password and will then be returned to the Input menu. See the example

below.
