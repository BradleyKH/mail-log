16 Abstract

Volume I: SCOUT PROJECT INFORMATION PROGRAMS

drivers.

This contractor report is a review of the user's operating
procedures for the Scout Project Automatic Data System, called
SPADS. SPADS is the result of the past seven (7) years of
software development on a Prime mini-computer located at the
Scout Project Office, NASA Langley Research Center, Hampton,
Virginia. SPADS was developed as a single entry, multiple
cross-reference data management and information retrieval
system for the automation of Project office tasks, including
engineering, financial, managerial, and clerical support.
Yhis volume, one (1) of three (3), provides the instructions
to operate the Scout Project Information programs in data
retrieval and file maintenance via the user friendly menu
